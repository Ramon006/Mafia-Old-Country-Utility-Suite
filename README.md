## 🗺️ What’s Inside This Atlas? (Core Modules)

This repository is structured like a well-organized crime family: each department knows its role, executes with precision, and reports to the central hierarchy. Here’s your introduction to the key figures in our operation.

### 1. 📜 The Historical Codex (Lore & Context)
Before you plan a heist, you must understand the history of the neighborhood. This module contains:
- **Extensive Interactive Timelines**: Navigate the pivotal years of the old country and the new world, with lore-friendly annotations.
- **Character Allegiance Trees**: Visual charts (text-based, but beautifully structured) that show the nuanced relationships between key figures—from blood oaths to bitter betrayals.
- **Cultural Glossary**: A comprehensive list of terms and phrases, translated and contextualized to enrich your understanding of the setting’s unique dialect and traditions.

### 2. 🧠 The Family Dynamic Simulator (Strategic Thinking)
This is the crown jewel of the repository. We provide a **logic-based simulation algorithm** (running on Python scripts, fully documented) that helps you model:
- **Influence Maps**: See how different actions in various districts might shift the balance of power.
- **Loyalty Metrics**: Understand the factors that solidify or erode trust, based on a complex set of in-universe variables.
- **Rival Faction Scenarios**: Plug in different "trigger" events to see a probability heatmap of potential responses from rival families.

This is a **critical thinking tool**, designed to make you a better analyst and pattern-recognizer. It is the difference between memorizing a route and being able to navigate any city.

### 3. ⚙️ The Integrator’s API (For Developers & Tinkerers)
Are you a modder looking to build your own quest lines? Or a data scientist looking for a fun dataset? We have a well-documented **RESTful API** that serves the raw data from our Atlas.
- **JSON/CSV Exports**: Pull the entire character relationship graph, event chronology, or item economy table for your own projects.
- **Interactive Documentation**: Every endpoint is explained with practical examples and use cases.
- **Rate Limiting & Fair Use**: We encourage innovation but ask that you respect our humble server infrastructure.

### 4. 🖥️ The Interactive Console (Terminal UI)
For those who prefer the raw power of the command line, we’ve crafted a **beautiful TUI (Text-User Interface)**.
- **Zero-Dependency Navigation**: All you need is a Python interpreter and a terminal that supports ANSI colors.
- **Rapid Query System**: Type in a character name or a location to instantly pull up our research files.
- **Offline-First Design**: Once cloned, the entire knowledge base is available at your fingertips, no internet connection required.

## 🚀 Getting Started (The Gentle Onboarding)

We've designed this to be as frictionless as acquiring a new cigar. You don't need to wrestle with complex dependency trees or deal with environment headaches.

**The "Castle Key" Method:**
1.  **The Archive Room**: Navigate to the "Releases" section of this repository. Download the latest `.zip` or `.tar.gz` archive of the full source tree. It's organized like a treasure chest—everything is in its proper compartment.
2.  **The Steward’s Intro**: Read the `CONTRIBUTING.md` and `CODEOFCONDUCT.md` files. Think of these as the ground rules for sitting at the table.
3.  **The Familiarization**: To run the core simulator, you will need a **Python environment** (version 3.9 or later). Don't worry—the scripts are pure Python, using only the standard library. No extra packages to fetch.
4.  **Reading the Maps**: To peruse the narrative texts, simply open the `.md` files in the `atlas/` folder. They are formatted for human eyes, not machines.

**For the Builder's Guild (Developers):**
1.  **Secure the Blueprints**: Grab the source archive as described above.
2.  **Initial Configuration**: Copy the `config.example.json` to `config.json` and adjust your preferences—colors, default language, etc.
3.  **Run the Oracle**: Execute the main script `atlas_api.py` from your terminal.
4.  **Read the Ledger**: The interactive API docs will be available at your localhost address. The instructions are in the `docs/` folder.

## 🛠️ Technology Stack & Architecture

- **Core Logic**: Python 3.10+, utilizing `dataclasses` and `json` for robust data handling.
- **Data Store**: JSON schema files for relations and events, making them easy to diff and merge.
- **Interface Layer**: Pure `argparse` and `curses` libraries for the TUI, ensuring portability.
- **Distribution**: GitHub Releases with auto-generated checksums (SHA-256) for security.
- **Database**: SQLite3 for the advanced query engine.

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| **Data Parser** | Python `json` | Validating and loading our lore files. |
| **Simulation Engine** | Python `math` | Calculating probability matrices. |
| **Text Interface** | `curses` | Creating the rich Terminal UI experience. |
| **API Server** | `http.server` | Serving the raw JSON data over HTTP for developers. |
